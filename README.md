# ✦ AI Resume Builder

An AI-powered resume and cover letter assistant that helps job seekers tailor their applications to specific job descriptions.

The application uses **Google Gemini API** to generate personalized cover letters, optimize resume content, identify important job-description keywords, and estimate ATS compatibility.

---

## 🚀 Features

### ✉️ Personalized Cover Letter

Generate a professional cover letter based on:

- Company name
- Experience level
- Job description
- Preferred writing tone
- Existing resume

### 📄 Resume Optimization

Get AI-generated suggestions for:

- Resume summary
- Skills
- Resume bullet points
- Achievement-focused content
- ATS-friendly wording

### 🔎 Keyword Match Analysis

Analyze the job description and identify:

- Important keywords
- Skills required by the role
- Keywords already present in the resume
- Missing keywords that could improve the application

### 📊 ATS Score Estimate

Receive an estimated ATS compatibility score from **0–100**.
